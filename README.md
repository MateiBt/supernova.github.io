# Supernova Guide 🌌

Welcome to the **Supernova Guide** - an open-source command center for Astronomy & Astrophysics Olympiad preparation. 

### Features:
* 🔭 **3D Planetarium**: Interactive observational practice.
* 📚 **Resources & Handouts**: Curated materials for celestial mechanics and astrophysics.
* 🧠 **Practice Problems**: Over 300+ problems to test your skills.
