How to Create & Use a Mistake Note

Step 01 · Title & Module

Tag the Problem

Click + Add Note and write the problem ID or concept name (e.g., USAAAO 2025 Q26 or Transit Impact Parameter), then pick which of the 16 modules it belongs to.

Step 02 · Error Type

Pick the Cause

Choose whether it was a Physical Trap (wrong assumption), a Math / Sign Slip, or a Unit Error. This updates the breakdown bars on your Analytics page.

Step 03 · LaTeX Support

Write the Correction

Write what went wrong and how to solve it properly. You can type math using LaTeX between \(...\) for inline math or $$...$$ for equations.

Step 04 · Review Queues

1d → 7d → 30d

New notes start in 1d Review. Once you review a note, click Advance Queue to move it to 7d Review and then 30d.
